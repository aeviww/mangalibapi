# mangalibapi

неофициальная документация и примеры работы с api mangalib и связанных сервисов: ranobelib, slashlib / yaoilib, hentailib и animelib.

Документация доступна на [lib.aevi.lol](https://lib.aevi.lol).

## важное замечание

этот проект не связан с официальными разработчиками перечисленных сервисов.

api неофициальный и может меняться в любой момент. возможны изменения маршрутов, ограничения частоты запросов, антибот-защита и различия между сервисами или регионами.

**актуально на 27.10.2026.**

## особенности использования

- **протокол:** используйте HTTP/2. HTTP/1.1 блокируется клоудфларе.
- **referer.** передавайте заголовок `Referer` в запросе. отсутствие заголовка, в некоторых запросах может приводить к `403 Forbidden`.

## навигация

## контрибьютинг

документация находится в процессе разработки, поэтому некоторые маршруты, параметры или особенности работы api могут быть ещё не описаны.

**контрибьютинг приветствуется**, если вы обнаружили новый маршрут, нашли неточность или хотите дополнить примеры, создайте issue или отправьте пр.

## возникли проблемы?

если вы столкнулись с ошибкой, обнаружили неточность в документации или хотите предложить улучшение, создайте [issue](https://github.com/aeviww/mangalibapi/issues) в репозитории проекта.

при описании проблемы укажите:
- какой маршрут использовался;
- параметры запроса;
