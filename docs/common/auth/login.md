# авторизация

`POST https://auth.lib.social/auth/login`

вход по почте и паролю.

## параметры

| параметр | тип | описание |
|---|---|---|
| `_token` | `string` | CSRF токен со страницы сайта |
| `login` | `string` | почта аккаунта |
| `password` | `string` | пароль |

## пример

получить токен и cookie можно скриптом [`examples/login.py`](../../../examples/login.py).

скрипт запрашивает почту и пароль, выполняет вход и выводит cookie из сессии.
