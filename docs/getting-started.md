# начало работы

этот раздел содержит базовые рекомендации для отправки запросов к неофициальному апи.

## требования к запросам

- **протокол:** используйте HTTP/2. HTTP/1.1 блокируется клоудфларе.
- **referer.** передавайте заголовок `Referer` в запросе. отсутствие заголовка, в некоторых запросах может приводить к `403 Forbidden`.

## константы

на данный момент задокументирована только одна константа - `Site-id`

- `1` - mangalib;
- `2` - slashlib / yaoilib;
- `3` - ranobelib;
- `4` - hentailib;
- `5` - animelib.

## возникли проблемы?

если вы столкнулись с ошибкой, обнаружили неточность в документации или хотите предложить улучшение, создайте [issue](https://github.com/aeviww/mangalibapi/issues) в репозитории проекта.

при описании проблемы укажите:
- какой маршрут использовался;
- параметры запроса;
- HTTP-статус и текст ошибки;
- ожидаемое и фактическое поведение.

перед публикацией убедитесь, что отсутствуют ваши конфиденциальные данные.
