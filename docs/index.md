# mangalibapi

неофициальный справочник по апи мангалиба и связанных сервисов.

## разделы

- [начало работы](getting-started.md) - базовые требования к запросам.
- [константы](constants.md) - `site_id` и другие известные значения.
- [ошибки](errors.md) - известные HTTP-ошибки и их возможные причины.
- [общие маршруты](common/index.md) - маршруты, общие для нескольких сервисов.
- [сервисы](services/index.md) - особенности и уникальные маршруты каждого сервиса.

## важное замечание

проект не связан с официальными разработчиками сервисов. API неофициальный, поэтому его поведение, доступность и маршруты могут меняться без предупреждения.

## возникли проблемы?

если вы столкнулись с ошибкой, обнаружили неточность в документации или хотите предложить улучшение, создайте [issue](https://github.com/aeviww/mangalibapi/issues) в репозитории проекта.

при описании проблемы укажите:
- какой маршрут использовался;
- параметры запроса;
- HTTP-статус и текст ошибки;
- ожидаемое и фактическое поведение.

перед публикацией убедитесь, что отсутствуют ваши конфиденциальные данные.
